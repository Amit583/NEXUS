# NEXUS

NEXUS is a local-first personal digital environment designed to
combine planning, execution, learning, knowledge, productivity,
psychology, automation, analytics and local AI into one connected GUI.

## Architecture

- React + TypeScript
- Tauri
- Python + FastAPI
- SQLite
- Ollama
- Local-first architecture

## Project Status

Foundation setup.

## Development

The project is being developed incrementally with testing and
validation at every major subsystem.
